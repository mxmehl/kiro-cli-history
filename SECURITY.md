# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately using [GitHub's private vulnerability reporting feature](https://github.com/mxmehl/kiro-cli-history/security/advisories/new) rather than opening a public issue.

You can expect an initial response within a few days. If the vulnerability is confirmed, a fix will be released as soon as reasonably possible, and you will be credited in the release notes unless you prefer to remain anonymous.

## Supported Versions

As this is a small, actively maintained tool, only the latest released version is supported with security fixes.
